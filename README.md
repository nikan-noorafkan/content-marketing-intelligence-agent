# Content Marketing Intelligence Agent

A standalone [Druve](https://druve.ai) AI agent for automated content marketing and SEO intelligence, ported from the original n8n workflow template: [**Automated content marketing intelligence with OpenAI, Ahrefs & multi-platform integration**](https://n8n.io/workflows/5979) by Nikan Noorafkan.

## What It Does

The agent gathers real-time competitive, keyword, and audience signals, then synthesizes structured JSON recommendations covering:

1. **Content topics to prioritize**
2. **Content formats by region**
3. **Publishing schedule**
4. **Competitive advantages to leverage**
5. **Audience pain points to address**

### Data Sources
- **Ahrefs (`api.ahrefs.com`)** — Organic traffic and backlink overview via Site Explorer v3.
- **SEMrush (`api.semrush.com`)** — Top organic keywords for the target competitor domain.
- **Reddit (`www.reddit.com`)** — Hot posts for the seed keyword subreddit to surface audience pain points, common questions, and high-engagement topics.
- **Optional Manual Inputs (`extra`)** — Paste exports from **BuzzSumo**, **Google Trends**, **AnswerThePublic**, or a Reddit `hot.json` fallback directly into the input payload.

## Running on Druve (BYOK)

This agent runs on [Druve](https://druve.ai) using **Bring Your Own Key (BYOK)** — buyers supply their own LLM provider credentials and optional data API keys.

### Declared Outbound Hosts
When publishing or running on Druve, declare the following three data-fetch hosts:
- `api.ahrefs.com`
- `api.semrush.com`
- `www.reddit.com`

### Input Format

Pass a JSON object (all fields optional; sources without an API key are skipped) or a plain-text seed keyword (Reddit-only mode):

```json
{
  "competitor_domains": "etoro.com",
  "seed_keywords": "forex trading",
  "target_regions": "US,UK,DE,FR,JP",
  "timeframe_days": 30,
  "ahrefs_api_key": "YOUR_AHREFS_API_KEY",
  "semrush_api_key": "YOUR_SEMRUSH_API_KEY",
  "extra": {
    "buzzsumo": [],
    "google_trends": {},
    "answerthepublic": [],
    "reddit": {}
  }
}
```

### Output Format

Returns a JSON object containing:
- `recommendations`: Structured JSON action items generated by the LLM.
- `data`: The processed `competitor_intelligence`, `keyword_opportunities`, and `audience_insights` payloads used to generate the recommendations.
- `errors`: Any non-fatal HTTP or parsing errors encountered for individual sources.
